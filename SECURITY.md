# Política de segurança

Relate vulnerabilidades em caráter privado para **contact@librecode.coop** com o assunto `Confidential security report: agent-skills`. Forneça um resumo, impacto, revisão afetada e uma reprodução com dados sintéticos. Não publique credenciais, dados reais ou detalhes de falhas não corrigidas em issues públicas. Nenhum SLA de resposta ou de correção é prometido sem acordo específico.

Escopo: instruções que induzam ações não autorizadas, injeções de prompt, vazamento de dados sensíveis, execução insegura de scripts, comprometimento de dependências/CI, e riscos na distribuição de plugins. O catálogo não substitui controles de segurança dos projetos consumidores. Antes de publicar evidências, elimine informações de clientes e infraestrutura privada.

**English:** Report vulnerabilities privately to `contact@librecode.coop`. Do not post unpatched issues, real credentials or customer data to public GitHub discussions.
